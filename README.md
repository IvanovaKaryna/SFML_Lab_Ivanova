# Лабораторна робота № 5

## Використання SFML в C++ проєкті. Використання пакетного менеджера vcpkg

**Варіант:** 10  
**Виконала:** студентка групи ФІТ 3-10, Іванова Карина  
**Рік:** 2026

## Мета роботи

Отримати навички створення та налаштування C++-проєкту у Visual Studio з використанням бібліотеки SFML, системи складання CMake та менеджера пакетів vcpkg.

## Опис проєкту

Програма моделює затухаючі коливання вантажу на пружині. Користувач може змінювати жорсткість пружини та коефіцієнт опору, призупиняти й відновлювати моделювання, а також перезапускати його.

## Використані технології

- C++
- SFML
- CMake
- vcpkg
- Visual Studio

## Керування програмою

- Space - пауза та продовження моделювання.
- R - перезапуск.
- ↑ / ↓  - збільшення та зменшення жорсткості пружини.
- ← / → - зменшення та збільшення коефіцієнта опору.

## Структура проєкту

- main.cpp - програмний код моделювання.
- CMakeLists.txt - налаштування складання проєкту.
- CMakePresets.json - конфігурація CMake.
- vcpkg.json - опис залежностей проєкту.

## Запуск проєкту

1. Відкрити папку проєкту у Visual Studio.
2. Переконатися, що vcpkg та залежність SFML налаштовані.
3. Виконати конфігурацію CMake.
4. Зібрати проєкт і запустити програму.

## Результат

Реалізовано графічну модель пружинних коливань із можливістю змінювати параметри системи та керувати моделюванням із клавіатури.
